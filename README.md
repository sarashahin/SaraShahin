#### Current research

**MetaDiffusion**: a conditional diffusion model that reconstructs species range maps from a few occurrence records, with ensemble-based uncertainty. It is trained on Lotka-Volterra metacommunity simulations, so every reconstruction can be checked against the true range. PhD work at Queen Mary University of London with Axel G. Rossberg.

- Poster B-S.B.31 at ECCB: [MetaDiffusion: A process-aware conditional diffusion model for multi-species spatial range reconstruction from sparse observations](https://eccb.performedia.com/poster/b-s-b-31-metadiffusion-a-process-aware-conditional-diffusion-model-for-multi-species-spatial-arranged-reconstruction-from-sparse-observations/)
